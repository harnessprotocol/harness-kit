# Harness Parity

Harness Parity was a capability grid in earlier releases. It is gone from the desktop
app. [Machine](/docs/apps/machine) replaced it: the same question, which tool has what,
now comes from the config actually on your machine, and a cell opens a drawer that
copies a resource from one tool to another.

To see which capabilities each tool supports, use the capability matrix on the
[home page](/). To check that compiled files still match `harness.yaml`, use the Drift
tab in Machine or run `harness check` from the CLI.
